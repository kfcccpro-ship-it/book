# MG 교재 재고관리

현재 기준본은 GitHub `main`입니다.

## 새 ChatGPT 채팅에서 작업 이어가기

새 채팅에서 아래 한 줄만 입력하세요.

**`교재관리 다음 작업 진행`**

Assistant는 저장소의 아래 파일을 읽고 최신 작업부터 이어갑니다.

1. `START_HERE_CHATGPT.md`
2. `PROJECT_STATE.json`
3. `PROJECT_HANDOFF_LATEST.md`

별도의 ZIP/백업파일 업로드나 PowerShell 배포는 기본적으로 필요하지 않습니다.
